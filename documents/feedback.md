## 1차 시도

전체적인 핵심 기능은 구현 성공, UI흐름이나 뒤로 돌아가기나 분석중 같은 의도적 마찰은 없음. 뭔가 딱딱하고 밋밋한 웹 완성.

### 수정 필요 부분

각 팀 표시하는 부분이 너무 눈에 안뜀. 글래스 스타일 그라디언트로 채우거나 해야할듯

블루평균, 레드평균이 각 팀에 붙어야함

페이지 자체에 마무리 페이지가 있어야 할듯. ‘내전 종료하기’ 와 같은 페이지로, 이번 세션의 총합 결과를 볼 수 있는 페이지와 평가할 수 있는 페이지, 피드백 페이지를 넣으면 좋을듯. 

개발자 커피 사주기 페이지도 좋겠네요(계좌 걸어놓깈ㅋ)

#### 참가자 페이지

- 검색창 개선 : 이름 입력 시 검색로직, 목록 보여주고 선택할 수 있게
- 팀원 추가 단계에서는 인원의 상세정보를 확인하기보다는, 그냥 한눈에 지금 어떤 계정을 추가했는지 볼 수 있게 수정
- 부캐라면 본캐 계정을 입력하세요 경고문 부착

#### 팀 제안 단계

- 블루 VS 레드 구도가 더 잘 보이도록 개선
- 각 팀의 총합 전력점수를 보여주고, 100분위로 나눠 51% vs 49% 이런식으로 표시
- AI 분석 팀 컬러 멘트

#### 게임 결과 입력

- 입력보조 창은 보조이기때문에, 작은 버튼으로 추가. 모달로 보조 입력 지원
- 각 KDA와 딜량 입력 PlaceHolder 개선 어떤 식으로 채워야하는지
- 폼 데이터 setState로 저장해서 사용해야할듯 저장 안하면 자꾸 날려먹음

#### 재밸런스

- UI 개선 : “팀” 중심 표시로 변경, 팀원들 티어와 이전 판 평가 표시(기대치 대비 플레이 F/D/C/B/A/OP) 표시,
- 트레이드된 팀원 표시 플레이어A ↔ 플레이어G 이런식으로 표시, 제안 팀목록에서도 교체된 팀원 border 강조
- 전판 대비 개인점수 상승 n% / 하강 n% 표시해야 볼게 있을듯

#### AI요약

- 무료 API인 gemini 모델로 변경
- 페이지 삭제. 팀 제안, 게임 결과, 재밸런스 페이지로 이동, 우측 AI플로팅 원형 캐릭터 느낌으로 변형, 말풍선으로 설명을 들어보세요 하기
