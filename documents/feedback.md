## 1차 시도

전체적인 핵심 기능은 구현 성공, UI흐름이나 뒤로 돌아가기나 분석중 같은 의도적 마찰은 없음. 뭔가 딱딱하고 밋밋한 웹 완성.

### 수정 필요 부분

각 팀 표시하는 부분이 너무 눈에 안뜀. 글래스 스타일 그라디언트로 채우거나 해야할듯

블루평균, 레드평균이 각 팀에 붙어야함

페이지 자체에 마무리 페이지가 있어야 할듯. ‘내전 종료하기’ 와 같은 페이지로, 이번 세션의 총합 결과를 볼 수 있는 페이지와 평가할 수 있는 페이지, 피드백 페이지를 넣으면 좋을듯. 

개발자 커피 사주기 페이지도 좋겠네요(계좌 걸어놓깈ㅋ)

#### 참가자 페이지

- 검색창 개선 : 이름 입력 시 검색로직, 목록 보여주고 선택할 수 있게
- 팀원 추가 단계에서는 인원의 상세정보를 확인하기보다는, 그냥 한눈에 지금 어떤 계정을 추가했는지 볼 수 있게 수정
- 부캐라면 본캐 계정을 입력하세요 경고문 부착

#### 팀 제안 단계

- 블루 VS 레드 구도가 더 잘 보이도록 개선
- 각 팀의 총합 전력점수를 보여주고, 100분위로 나눠 51% vs 49% 이런식으로 표시
- AI 분석 팀 컬러 멘트

#### 게임 결과 입력

- 입력보조 창은 보조이기때문에, 작은 버튼으로 추가. 모달로 보조 입력 지원
- 각 KDA와 딜량 입력 PlaceHolder 개선 어떤 식으로 채워야하는지
- 폼 데이터 setState로 저장해서 사용해야할듯 저장 안하면 자꾸 날려먹음

#### 재밸런스

- UI 개선 : “팀” 중심 표시로 변경, 팀원들 티어와 이전 판 평가 표시(기대치 대비 플레이 F/D/C/B/A/OP) 표시,
- 트레이드된 팀원 표시 플레이어A ↔ 플레이어G 이런식으로 표시, 제안 팀목록에서도 교체된 팀원 border 강조
- 전판 대비 개인점수 상승 n% / 하강 n% 표시해야 볼게 있을듯

#### AI요약

- 무료 API인 gemini 모델로 변경
- 페이지 삭제. 팀 제안, 게임 결과, 재밸런스 페이지로 이동, 우측 AI플로팅 원형 캐릭터 느낌으로 변형, 말풍선으로 설명을 들어보세요 하기

## 2차 시도

전체 핵심 흐름·AI·마무리까지 동작. 이번엔 딱딱한 인상과 정적 레이아웃을 걷어내고, 모션·정보 구조·대치 구도를 다듬는다.

#### 공통

- 랜딩으로 버튼 너무 큼 → 고정 상단 배너 스타일로 변경. 가운데 정렬된 로고 스타일로
- 애니메이션 추가. 각 단계 넘어갈 때 모든 박스 페이드 아웃, 새 콘텐츠 박스들은 항상 박스 → 타이틀 → 리스트나 주요 콘텐츠 등장
- 참가자 등록 외 모든 플레이어 카드들은 블루팀은 좌→우로 슬라이드 인, 레드팀은 우→좌 방향으로 슬라이드 인
- 모든 애니메이션은 ease-ease 베지어 곡선 적극 활용, 자연스러운 모션 지향

#### 랜딩

- 그냥 페이지에 대한 정보 → 시작하기로 넘어가는게 좋을듯

#### (추가) 대시보드

- '안녕하세요, 총무 {사용자 플레이어 이름}님'
- 내 정보 추가 → 플레이어 선택해서 나로 추가하기
- 저장된 내전 세션 목록(그리드 카드 스타일)
    - 내전 상태(준비중, 진행중, 완료)
    - 내가 내린 평점

#### 참가자 등록

- 모든 플레이어가 다 등록하면서 보일 수 있도록 변경
    - 안내 메세지를 박스에 넣지 않고, 검색창 상단에 작은 텍스트로 수정
    - 등록 플레이어 리스트 크기 50% 줄이고, 왼 5명 오른쪽 5명 왼쪽줄 → 오른쪽줄로 순차적으로 채워지게 변경
    - 상세 정보는 아코디언이 아닌 호버 시 플로팅 모달로 변경
- 팀 제안하기 버튼 활성화 시 그라디언트 애니메이션

#### 팀 제안

- 팀 내 팀원들 리스트 카드 방향 개선. 현재 좌측 정렬로 되어있는데, 블루팀은 오른쪽 정렬 플레이어 카드로 대치구도 더 강조
- 팀 박스 타이틀과 내용도 블루팀은 우측정렬
- 이 구성으로 시험 판 버튼 팀 분석 하단에 버튼 리스트 구역으로 변경
- 선수 추가 교체 부분 각 팀 박스에 버튼으로 추가
    - 클릭 시 블루팀이면 좌측에, 레드팀이면 우측에 미니 플레이어 추가 모달 플로팅
- 팀 밸런스 근거는 1판 팀 제안 박스 우측 상단 밸런스 근거 보기 아이콘으로 추가, 호버 시 상세 근거 박스 플로팅

#### 게임 결과

- 블루팀 멤버 카드 우측정렬로 수정
- 1판 2판 3판 박스 우상단으로 고정
- 모든 게임 참가한 플레이어 한명 최근 게임 목록 불러오고, 게임 선택해서 데이터와 스코어 불러올 수 있도록 구현
- 4판째가 아니더라도 내전 종료 버튼 존재해야 함

#### 재밸런스

- 교체된 팀원 보더 강조, 교체된 팀원이 누구인지 표시

#### 내전 종료

- 최종 승리팀 언급, 제일 큰 박스 컬러 해당팀컬러로 표시
- 판별 결과 칩 또한 컬러 박스에 강조
- 성과, 피드백에 별점 선택 1-5 기능 추가

## 4차 시도(UI 피드백, )

#### 헌법

- 예외 언급이 있는 페이지가 아니라면, 모든 페이지에 전 단계, 혹은 다음단계, 결과 도출, 팀 제안하기 버튼이 스크롤을 하지 않고도 클릭할 수 있어야 함.

#### 로직

- 내전 결과 점수 비율 수정 70:30 → 90:10 비율로 추가, 감점하면 좋겠음. 성적과 별개로 실력은 크게 변하지 않을 수 있음

#### 공통

- 전체적인 애니메이션 속도 70%정도로 느리게 설정, UI가 순차적으로 등장
    - ex) 맨 위 박스 등장(타이틀 박스), 두 팀 박스 등장, 팀원들 채워짐 한박자씩 진행
- AI가 대답하는 텍스트에 애니메이션 적용. 한글자씩 뱉어줘서 말하는 것처럼
- AI우측 사이드바 형태 좋음, 그러나 좌측 사이드바를 열면 메인 페이지가 왼쪽으로 밀려나야 맞을듯. 현재는 오버레이되어서 화면을 가림
- AI가 md문법으로 결과를 뱉는데, 어느정도는 해석된 MD문법으로 보여줘야 할것으로 보임
- AI 캐릭터화가 필요할듯. 분석중.. 이 아니라 고민하는 표정이 나온다던가
- AI 현재는 저녁메뉴같은 질문에도 대답함. 토큰이 위험함으로 절대 내전과 리그오브레전드 플래이어에 대한 질문에만 답해야 함
- AI예시 질문, 질문 입력 후 바로 대답을 준비하는데, 현재는 그 상태에서도 중복 질문이 가능함. 금지.
- 왜 이렇게 계산 되었나요? 아코디언은 넣지 말고, 다른 페이지에 추가 (점수 책정 방식설명 페이지) 각 페이지에서는 i 아이콘으로 이동할 수 있는 정도만 구현
- 여기저기 등장하는 플레이어카드의 성과, 티어, 라인 아이콘 등이 표시되는 칩 형태가 있는데, 블루팀카드 콘텐츠가 우측 정렬이면 칩들도 flex-and여야 함
    - 칩 상하단 여백 안맞음
- 플레이어카드가 UI와 구분이 어려움. 백그라운드를 채워야 할듯. 티어 엠블럼의 컬러를 딴 은은한 그라디언트면 좋을거 같음.
- 플레이어 태그는 표시할 필요 없음. 게임명만 보여주셈

#### 대시보드

- 내 플레이어는 오른쪽 상단에 소환사 아이콘으로 표시. 메인에 크게 나오지 말것.
- 내전 생성 시 내전 이름 등록 필요, 상태에 따라 카드 컬러 변경
- 마무리까지 단계가 진행되었으면 내전 종료 상태로 넘어가야함(지금 안됨)

#### 참가자 등록

- 버그1 : 사용자 목록에서 좌측을 다 채우고 플레이어를 우측에 채우는 순서가 되면, 높이값이 100%가 됨(플레이어 카드가 너무 높음)
- 사용자 태그가 없으면 #KR1 붙혀서 검색하는건 옳은 판단으로 보임, 현재는 너무 귀찮음, 결과가 없을 때, ‘플레이어 태그가 #KR1이 아닐 경우 자동검색이 작동하지 않을 수 있습니다. 본 플레이어의 정확한 태그를 확인 해 주세요’ 알려줄 것

#### 시험 판 결과 입력

- 라인 선택이 다른 팀원과 겹칠 수 없음
- 캐릭터 목록 제공, ID를 사용자가 알 리가 없음. 초상화와 이름
- 태그는 필요 없음 차라리 소환사 아이콘으로 쓰셈
- 입력칸이 너무 큼. fontSize를 0.6vw 정도로 해주세요
- 어차피 사람들은 이거 손으로 안넣음. 보조 입력 강조
- 점수판 이미지 예외처리 필요 : 만약 플레이어 감지가 이상하면, 수동으로 매칭할 수 있게

#### 결과 인트로

- 전체적인 템포가 너무 빠르지 않도록 조정 평균 대기 시간 1- 2초로 맞추기
- MVP의 KDA 점수와 챔피언 피해량 명시
- 기대 이상의 플레이어는 이번 내전에서의 당신의 실력은 플레티넘 4 급이었습니다 하고 랭크 엠블럼 붙혀주기
- 기대치 대비 최악의 플레이어 선정 : 위 플레이어는 이번 내전의 범인입니다. 아, {정글/라이너/서폿/원딜} 차이라구요? 그건 비밀인데.. 본인만 즐거우면 된거죠! 다음 내전에서는 더 좋은 모습 보여줄 거에요
    - MVP화면에서 띄우기 → 최악의 플레이어는?

## 5차 시도(추가 UX)

#### 플레이어 카드

- 호버 시 상세가 보기 불편함 → **아코디언**으로 변경

#### 재밸런스

- 재정립 후 멘트 필요: 「팀원 n명을 교체했습니다.」 또는 「황금밸런스의 판입니다. 팀원 변경은 불필요!」
- 교체된 팀원 표시가 빈약함 → **트레이드 아이콘** + **카드 컬러 강조**
- 「이전 팀으로 재도전하기」: 팀원 변경만 초기화(직전 팀 복원), **성적은 유지**. 헤더 우상단 배치

#### AI

- 플로팅(닫힌) 상태에서 말풍선: 「AI 분석을 들어보세요!」

#### 시험 판 입력

- 점수판 이미지 분석은 **beta** 표기 (작은 컬러 글씨)
