# MVP 릴리스 수용 기준 체크리스트

> **기준:** [spec.md](./spec.md) §9 · v2.1 (2차 반복)

> **작성일:** 2026-07-29  
> **상태:** 검증 대기 (코드 구현 완료 · 아래 칸은 QA용)

검증 시 각 항목을 통과하면 `[x]`로 바꾸고, 비고에 이슈/재현 조건을 남긴다.

### 구현 메모 (문서 동기화)

- 참가자 2~10명 등록, 8·10명 준비 시 `n/10 · 팀 제안하기` CTA로 `/team` 이동
- 전력 카드: LoL 티어 엠블럼(프로필 왼쪽) + OP/1~4 내부 등급 + 라인 아이콘
- `unrated`(이전 기록 없음)는 `기록 부족` 중립 배지로 표기 — F 등급·범인 마크와 구분
- 팀 화면: 블루/레드 색 구분 컬럼 + 헤더 평균 티어 + 100분위 전력 비율 바
- 시험 판 수동 입력: `20,170` / `1.50` 등 쉼표·소수 허용 (`parseStatNumber`)
- 보조 입력: 경기 ID 자동 채움 · 점수판 이미지(Gemini) → 검토·재매핑 → 폼 적용
- 재밸런스: 이동 인원 트레이드 표시 + 직전 판 등급·꿀벌 + 개인 점수 증감(▲/▼)
- AI 요약: `/summary` 페이지 없음 — team/trial/rebalance/finish **플로팅 어시스턴트**(🐝)
- ReasonPanel: players / team / trial(70:30·꿀벌·기록 부족) / rebalance
- 키 거부(401/403)는 `RIOT_UNAUTHORIZED` / `GEMINI_UNAUTHORIZED`로 분리 → "키 만료·갱신 후 재시작" 안내
- 마무리 `/finish`: 판별 결과·티어 변화·하이라이트·평가/피드백·후원(계좌 복사)

## E. E2E 시나리오 (권장 1회)

```
1. 새 내전 생성
2. 참가자 8명 또는 10명 등록 (기록 없는 참가자 1명 포함 → 기록 부족 배지)
3. 1판 팀 제안 확인 → 전력 비율 바 → 스왑 1회 → 저장
4. 어시스턴트(🐝) 열기 → normal 요약(팀 색 멘트) 확인
5. 시험 1판: 승패만 저장 → 꿀벌·등급 미판정 확인 → 2판 제안
6. 시험 2판: 경기 ID 또는 이미지 또는 수동(KDA·딜량) 저장 → 등급 산출
7. 시험 3판 저장 → 4판 재밸런스 트레이드·증감 확인
8. 어시스턴트 normal → friend 전환 후 톤 차이·범인 후보 확인
9. 내전 종료 → /finish 총합·티어 변화·하이라이트 확인
10. 평가·피드백 입력 저장 → 후원 계좌 복사
```
